# TFT Build Advisor · Set 18 (로컬 서버 베타)

## 실행

Python 3.9 이상 필요. 추가 패키지 설치 없음.

- Windows: `start_windows.bat` 더블클릭
- macOS / Linux: 터미널에서 `sh start_mac_linux.sh`
- 또는 `python server.py` (Windows에서 `py server.py`도 가능)

터미널에 일반 사용자 주소, 관리자 로그인 주소, **이번 실행의 관리자 비밀번호**가 표시됩니다.

- 일반 사용자: `http://127.0.0.1:8765/`
- 관리자 로그인: `http://127.0.0.1:8765/login`

관리자 비밀번호는 서버 시작 시 임의로 생성됩니다. 고정하려면 실행 전에 `TFT_ADMIN_PASSWORD` 환경 변수를 지정하세요. 서버를 재시작하면 임시 비밀번호와 세션이 변경됩니다. 관리 세션 유효기간은 8시간입니다.

## 데이터

최초 사용자가 접근할 때 CommunityDragon 한국어 JSON 다운로드를 시도합니다. 관리자 페이지에서 수동 갱신 또는 파일 업로드가 가능합니다. 검증된 파일은 `data/ko_kr.json`에 캐시됩니다. 인터넷이 차단되면 관리자가 JSON을 다운로드해 업로드할 수 있습니다.

공식 메타 승률/덱 통계는 아직 연결하지 않았습니다. 조합 후보는 특성·보유 기물 기반의 **실험적 휴리스틱**이며 실전 강함을 보장하지 않습니다. 세트 18 데이터 구조가 제공처에서 변경되면 파서 수정이 필요할 수 있습니다.

## 보안 범위

관리자 HTML 및 관리 API는 **서버 측 인증**으로 차단됩니다. 일반 사용자 페이지에 관리자 링크나 관리 기능은 없습니다. 서버는 기본적으로 `127.0.0.1`에서만 접근할 수 있으며 외부 공개용이 아닙니다. 실제 인터넷 배포 시에는 HTTPS, 호스팅 환경의 인증 및 보안 설정을 별도로 적용해야 합니다.

## 문제 해결

버튼이 반응하지 않으면 HTML 파일을 직접 더블클릭하지 말고 서버 주소로 열어야 합니다. 브라우저 개발자 도구 콘솔에서 오류를 확인하세요. 초기 데이터 다운로드 실패 시 관리자 페이지에서 파일을 업로드하세요.
